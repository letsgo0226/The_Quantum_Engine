# GitHub Actions

1. Open **Actions** in this repository.
2. Run **ATGC v42 iOS Build** for an unsigned simulator app.
3. Run **ATGC v42 Device Archive (unsigned)** for an unsigned iOS device archive.

These outputs are not signed IPAs. Installing on a physical iPhone requires Apple code signing and an appropriate distribution method. The simulator app cannot be installed on an iPhone. The original Python reference sources are included separately.
